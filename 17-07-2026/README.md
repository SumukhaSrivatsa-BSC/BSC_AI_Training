# Prompt Engineering - Questions & Answers

A comprehensive collection of **Prompt Engineering** concepts along with practical coding exercises and real-world prompt design techniques using **Python**, **OpenAI APIs**, and **Large Language Models (LLMs)**.

This repository is designed for beginners and aspiring AI/ML Engineers to understand the fundamentals of Prompt Engineering and apply effective prompting techniques through hands-on examples.

## Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Prompt-Engineering.git
```

Move into the project

```bash
cd Prompt-Engineering
```

Install dependencies

```bash
pip install openai transformers jupyter
```
