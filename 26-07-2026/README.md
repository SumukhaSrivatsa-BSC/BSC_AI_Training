# Python Comprehensions

A collection of simple Python programs demonstrating **List Comprehensions** and **Dictionary Comprehensions**, including nested comprehensions. Each example compares the traditional loop-based approach with Python's concise and efficient comprehension syntax.  

---

## Repository Contents

### 1. List Comprehension

- Creating new lists using comprehensions
- Replacing traditional `for` loops
- Modifying existing list elements

---

### 2. Dictionary Comprehension

- Creating dictionaries efficiently
- Replacing traditional dictionary construction
- Key-value pair generation

---

### 3. Nested List Comprehension

- Flattening nested lists
- Using multiple `for` loops in a single comprehension
- Cleaner alternative to nested loops

---

### 4. Nested Dictionary Comprehension

- Creating dictionaries from iterable data
- Generating key-value mappings
- Simplifying nested dictionary creation

---
