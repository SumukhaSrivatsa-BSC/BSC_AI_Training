# 📦 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/LLM-Fundamentals.git
```

Move into the project

```bash
cd LLM-Fundamentals
```

Install dependencies

```bash
pip install torch transformers sentence-transformers scikit-learn
```
