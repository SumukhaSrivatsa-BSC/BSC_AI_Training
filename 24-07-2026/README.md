# Retrieval-Augmented Generation (RAG) Learning Repository

A comprehensive collection of **Retrieval-Augmented Generation (RAG)** concepts, assignments, hands-on labs, and real-world implementations using **LangChain**, **Vector Databases**, **Semantic Search**, and **Large Language Models (LLMs)**.

This repository is designed for beginners and aspiring AI/ML Engineers to build a strong understanding of modern RAG systems through theory, practical coding exercises, and end-to-end applications.

## Installation

Clone the repository

```bash
git clone https://github.com/yourusername/RAG-Learning-Repository.git
```

Move into the project

```bash
cd RAG-Learning-Repository
```

Install dependencies

```bash
pip install langchain transformers sentence-transformers faiss-cpu openai torch jupyter
```

## Running the Examples

Simply open any notebook and run all cells.
