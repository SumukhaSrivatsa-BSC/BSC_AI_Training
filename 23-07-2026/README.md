# Retrieval-Augmented Generation (RAG) Assignment

A comprehensive collection of **Retrieval-Augmented Generation (RAG)** concepts along with theoretical explanations, practical workflows, and real-world applications for building knowledge-grounded AI systems.

This repository is designed for beginners and aspiring AI/ML Engineers to understand the fundamentals of RAG, semantic search, vector databases, embeddings, and modern retrieval techniques used in Large Language Model (LLM) applications. :contentReference[oaicite:0]{index=0}

## Installation

Clone the repository

```bash
git clone https://github.com/yourusername/RAG-Assignment.git
```

Move into the project

```bash
cd RAG-Assignment
```

Install dependencies

```bash
pip install transformers sentence-transformers faiss-cpu jupyter
```
