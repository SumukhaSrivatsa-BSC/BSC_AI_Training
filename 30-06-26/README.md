# Python Programming Fundamentals

A comprehensive collection of **Python programming concepts** ranging from basic syntax to Object-Oriented Programming (OOP), file handling, exception handling, logging, functions, and a mini AI project.

This repository is designed for beginners to build a strong foundation in Python through theory, practical examples, and hands-on notebooks.

## Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Python-Programming-Fundamentals.git
```

Move into the project

```bash
cd Python-Programming-Fundamentals
```

---

## Running the Notebooks

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open any notebook and run all cells.
