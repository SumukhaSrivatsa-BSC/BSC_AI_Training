# AI-Powered Intelligent Search System

A capstone project demonstrating an **AI-powered semantic search system** using **Sentence Transformers** for embeddings and comparing two popular vector databases—**FAISS** and **ChromaDB**—for efficient document retrieval.

This project is designed for beginners and aspiring AI/ML Engineers to understand the complete workflow of semantic search, vector embeddings, and vector databases through a hands-on implementation.

## Installation

Clone the repository

```bash
git clone https://github.com/yourusername/AI-Powered-Intelligent-Search-System.git
```

Move into the project

```bash
cd AI-Powered-Intelligent-Search-System
```

Install dependencies

```bash
pip install sentence-transformers transformers faiss-cpu chromadb pandas numpy jupyter
```

---

## Running the Project

Open the notebook and run all cells.

jupyter notebook
